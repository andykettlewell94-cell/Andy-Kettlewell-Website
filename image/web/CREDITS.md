# Photo credits

Who took each photo used on andykettlewell.co.uk. These credits also live in
two other places:

- the `data-photographer` attribute on each image in the HTML
- the copyright field embedded in the JPEG file itself

Gallery photos come in two sizes: `portfolio/name.jpg` for the page and
`portfolio/full/name.jpg` for the full-screen viewer. Both carry the same credit.

Photos marked "to confirm" have no known photographer yet. Add the name here,
in the HTML attribute, and in the file with:

```
sips -s artist "Name" -s copyright "© Name" path/to/photo.jpg
```
