# Photo credits

Who took each photo used on andykettlewell.co.uk.

Each credit is stored in three places:

- the `data-photographer` attribute on the image in the HTML
- the artist and copyright fields embedded in the JPEG
- this list

Gallery photos come in two sizes, `portfolio/name.jpg` for the page and
`portfolio/full/name.jpg` for the full-screen viewer. Both carry the credit.
